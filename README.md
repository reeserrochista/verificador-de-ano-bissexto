Verificador de Ano Bissexto
Um programa simples em Python que verifica se um determinado ano é bissexto.

Sobre
Este projeto foi criado para praticar conceitos básicos de programação, como entrada de dados, estruturas condicionais, operações aritméticas e operadores lógicos.

Como Funciona
O programa solicita que o usuário informe um ano e verifica se ele é um ano bissexto.

Um ano é bissexto quando:

É divisível por 4.

Se for divisível por 100, também deve ser divisível por 400.

Tecnologias
Python

Como Executar
Clone o repositório:

git clone https://github.com/SEU-USUARIO/leap-year-checker.git

Entre na pasta do projeto:

cd leap-year-checker

Execute o programa:

python main.py

Exemplo
Digite um ano: 2024

2024 é um ano bissexto!
